# 安大石溪学院应用物理课程资料库

面向安大石溪学院应用物理专业学生的课程资料共享库。

本仓库由安大石溪学院应用物理专业24级在读学长个人整理，面向在校同学分享课程学习资料。

截至2026年8月23日，资料整理者在校期间绩点排名前十。现将学习过程中积累的课件、笔记、作业和复习资料整理分享，希望能为学弟学妹提供一些帮助。

## 访问资料库

[https://wenhuirdics-wq.github.io/Course-Materials-from-SBIAHU-Physics/](https://wenhuirdics-wq.github.io/Course-Materials-from-SBIAHU-Physics/)

## 使用方法

课程资料均存放在 GitHub [Releases](../../releases) 中。

进入资料库网站后，可以：

- 按学期筛选课程
- 搜索课程名称
- 查看课程资料大小
- 点击对应课程直接下载

## 资料内容

资料主要包括：

- 课程课件
- 作业、习题及部分参考答案
- 课程笔记
- 历年试题（部分课程提供）
- 其他学习资料

目前资料主要覆盖大一至大二的必修课，后续会根据整理进度持续补充。

## 资料说明

资料内容来自个人整理和学习过程中积累的资料，完整性有限，部分课程可能存在资料较少或更新不及时的情况，我会尽可能完善。

资料仅作学习分享，请勿用于商业用途；使用资料时请遵守相关版权和课程规定，并以任课教师的要求为准。
